pyhealth.tasks.MultimodalSurvivalPrediction
===========================================

Overall survival (time to death, right-censored at last follow-up) from
multimodal TCGA embeddings and clinical features, following Song et al.,
`Multimodal Cancer Modeling in the Age of Foundation Model Embeddings
<https://proceedings.mlr.press/v297/song26a.html>`_, ML4H 2025.
